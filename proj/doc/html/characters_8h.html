◆ update_and_spawn_player_units()

void update_and_spawn_player_units ( void )

Updates the state of all active player units. This includes movement, AI logic (like attacking), and managing animations. It does not handle direct spawning from input, but can manage timed or conditional spawning.

Updates the state of all active player units. This includes movement, AI logic (like attacking), and managing animations. It does not handle direct spawning from input, but can manage timed or conditional spawning.

  • Checks for enemies in range and initiates attacks.
  • Manages attack cooldown and animation.
  • Moves units forward if no enemy is in range.
  • Handles units reaching the screen edge (damaging enemy base).
  • Despawns units that move off-screen. This function does not actually spawn units; spawning is handled by add_player_unit_to_game.
