\doxysubsection{Detailed Description}
Manages the main game loop, game states, and event dispatching. 

This file contains the central game loop {\ttfamily \doxylink{game_state_8c_a5afa3e5ed97aee6a63292a37260a383e}{game\+Loop()}}, which handles hardware interrupts (timer, keyboard, mouse) and dispatches events to appropriate handlers based on the current game state.

void game\+Loop (\begin{DoxyParamCaption}\item[{void}]{}{}\end{DoxyParamCaption})}



The main game loop. 

Initializes game components and then enters a loop to process hardware interrupts (timer, keyboard, mouse). It calls appropriate handlers for these events and manages screen updates with double buffering. The loop continues until the game state is set to EXIT.
