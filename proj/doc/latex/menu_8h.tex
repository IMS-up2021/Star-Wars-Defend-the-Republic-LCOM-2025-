\doxysubsection{Detailed Description}
Defines coordinates for menu buttons and declares functions for loading and drawing menu and instructions screens. 

This file contains macros for the bounding boxes of interactive menu elements (buttons) and function prototypes for managing the visual assets and rendering of different menu states.
