Updates all active player units and handles spawning logic. This function iterates through active player units, updating their state\+: 

Updates the state of all active player units. This includes movement, AI logic (like attacking), and managing animations. It does not handle direct spawning from input, but can manage timed or conditional spawning.


\begin{DoxyItemize}
\item Checks for enemies in range and initiates attacks.
\item Manages attack cooldown and animation.
\item Moves units forward if no enemy is in range.
\item Handles units reaching the screen edge (damaging enemy base).
\item Despawns units that move off-\/screen. This function does not actually spawn units; spawning is handled by {\ttfamily add\+\_\+player\+\_\+unit\+\_\+to\+\_\+game}. 
\end{DoxyItemize}
