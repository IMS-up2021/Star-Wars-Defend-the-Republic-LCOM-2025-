Updates the state of all active enemy units and handles spawning. This includes movement, AI logic (like attacking), managing animations, and periodic spawning of new enemies.


\begin{DoxyItemize}
\item Spawns new enemies periodically.
\item Checks for player units in range and initiates attacks.
\item Manages attack cooldown and animation.
\item Moves enemies forward if no player unit is in range.
\item Handles enemies reaching the player base (damaging player base).
\item Despawns enemies that move off-\/screen or are defeated. 
\end{DoxyItemize}
