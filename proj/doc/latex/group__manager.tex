int exit\+\_\+game (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Cleans up resources and exits the game. 

This function handles the graceful termination of the game. It should unsubscribe all interrupts, free allocated memory (like graphics buffers), restore the system to text mode, and perform any other necessary cleanup before the program terminates.

\begin{DoxyReturn}{Returns}
int 0 upon successful exit (though often this function might not return if it calls {\ttfamily exit()}), non-\/zero if an error occurs during cleanup (less common for an exit function).
\end{DoxyReturn}
Cleans up resources and exits the game.

This function performs the necessary cleanup operations before the game exits\+:
\begin{DoxyEnumerate}
\item Unsubscribes mouse interrupts.
\item Unsubscribes keyboard interrupts.
\item Unsubscribes timer interrupts.
\item Attempts to re-\/enable mouse data reporting. This step is unusual for an exit sequence, as disabling data reporting or resetting the mouse to defaults is more common. It might be intended to restore a specific mouse state expected by the OS/environment.
\item Exits the graphics mode and returns to text mode using {\ttfamily vg\+\_\+exit()}.
\end{DoxyEnumerate}

If any unsubscription or cleanup step fails, it prints an error message and returns an error code (1). {\ttfamily fflush(stdout)} is used to ensure error messages are displayed immediately, which is useful if the program terminates abruptly afterwards.

\begin{DoxyReturn}{Returns}
int 0 upon successful cleanup of all components, 1 if any error occurs. 
\end{DoxyReturn}

int initialize\+\_\+graphics (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Initializes the graphics subsystem. 

This function is responsible for setting the desired video mode, mapping video memory, initializing drawing buffers, and preparing the system for graphical output. It typically calls {\ttfamily set\+\_\+graphic\+\_\+mode} from the graphics module.

\begin{DoxyReturn}{Returns}
int 0 upon successful initialization, non-\/zero otherwise.
\end{DoxyReturn}
Initializes the graphics subsystem.

This function performs several critical setup steps\+:
\begin{DoxyEnumerate}
\item Subscribes to interrupts for the timer, keyboard, and mouse.
\item Stores the IRQ bitmasks for these devices in global variables ({\ttfamily timer\+\_\+irq\+\_\+set}, {\ttfamily kbd\+\_\+irq\+\_\+set}, {\ttfamily mouse\+\_\+irq\+\_\+set}).
\item Sends a command to the mouse to enable data reporting.
\item Initializes the frame buffer for the specified graphics mode (VBE\+\_\+1024p\+\_\+\+DC).
\item Sets the video controller to the specified graphics mode.
\item Sets the frequency of timer 0 to 60 Hz.
\item Loads all necessary visual assets for the menu, instructions screen, and the main game.
\end{DoxyEnumerate}

If any step fails, it attempts to clean up by unsubscribing any previously subscribed interrupts and then returns an error code (1).

\begin{DoxyReturn}{Returns}
int 0 upon successful initialization of all components, 1 if any error occurs. 
\end{DoxyReturn}
