void load\+\_\+menu\+\_\+assets (\begin{DoxyParamCaption}\item[{void}]{}{}\end{DoxyParamCaption})}



Loads all necessary visual assets for the main menu screen. 

This function is responsible for loading images, fonts, or any other resources required to display the main menu. These assets are typically loaded into memory once, for example, at the start of the menu state.

Loads all necessary visual assets for the main menu screen.

This function specifically loads the background XPM image for the menu using {\ttfamily xpm\+\_\+load}. The loaded pixmap data is stored in {\ttfamily bg\+\_\+menu} and its properties (like width and height) in {\ttfamily menu\+\_\+bg}. It assumes {\ttfamily menu\+\_\+bg\+\_\+xpm} (an array of strings defining the XPM) and {\ttfamily XPM\+\_\+5\+\_\+6\+\_\+5} (the desired XPM image type) are defined elsewhere. The global variables {\ttfamily bg\+\_\+menu} (pointer to pixmap data) and {\ttfamily menu\+\_\+bg} (xpm\+\_\+image\+\_\+t structure) are updated by this function.
